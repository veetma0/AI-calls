- **22 теста VoxEngine-сценария** прошли в Node VM с подменёнными телефонными и AI-событиями: одноразовый набор, персонализация до media, перебивание, остановка, итог, отказ, повторная доставка событий и завершение.

- Панель проверена в браузере в mock: вход → контакт → очередь → завершённая симуляция → просмотр текста → пауза → DNC. Заблокированный контакт получил неактивную кнопку «Не звонить».

- ZIP проверен на целостность: `.env`, реальные ключи, рабочая база, тестовые контакты и `.venv` отсутствуют.

**[GitHub Actions: успешный запуск](https://github.com/veetma0/AI-calls/actions/runs/40428283768)** повторил Python/Node-тесты на Ubuntu с Python 3.13 и Node 22, собрал образ Docker, поднял Compose с ограничениями доступа к файлам, дождался healthy и получил успешный ответ `/health`. После проверки тестовые контейнеры и том удалены.

В Python-тестах есть одно предупреждение о будущем изменении `Starlette TestClient` в части клиента httpx; тесты проходят. Это предупреждение тестовой зависимости, не ошибка запуска приложения. Обновление зависимостей требует повторной проверки.
