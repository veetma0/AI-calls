# Провайдеры, российский номер и стоимость

Проверено по публичным документам 27 октября 2026 года. Эта реализация использует **Voximplant Platform/VoxEngine + ElevenLabs Agents**. Настройка собственного кабинета, активация номера, реальный звонок и списания должны быть проверены отдельно: локальные тесты их не доказывают.

## Что отвечает за звонок

Voximplant предоставляет номер и соединение с телефонной сетью. Сценарий VoxEngine после ответа абонента подключает ElevenLabs, который ведёт голосовой разговор. Приложение хранит очередь и результаты, проверяет согласия и запреты на повторный контакт. Оно не принимает аудиопоток и по умолчанию не записывает аудио.

**Platform и Kit — разные продукты/режимы работы.** Для JS-сценария этого проекта нужен Platform. Условия тестирования и визуальные кампании Kit нельзя автоматически переносить на него.

### Номер и Caller ID

В панели Platform: **Numbers → Buy a new phone number → Russian Federation → тип/город**. После активации: своё приложение → **Numbers → Attach**, затем правило **Routing** с исходящим сценарием этого проекта. Реальный номер должен быть разрешён к использованию; статус покупки не равен успешной активации. См. [официальный порядок](https://docs.voximplant.ai/getting-started/network-options/phone-numbers-pstn) и [поля статуса номера](https://voximplant.com/docs/references/httpapi/structure/attachedphoneinfotype).

Для исходящих нужен действующий Caller ID — номер, отображаемый получателю. Практичнее использовать свой активный арендованный номер Voximplant. Подтверждение обычного мобильного номера через Caller ID не переносит его входящие с SIM в облако и не отменяет требования российского маршрута. Тестовый номер Voximplant нельзя использовать как исходящий Caller ID. [Сценарии PSTN](https://voximplant.com/docs/guides/calls/scenarios), [подтверждение своего номера](https://voximplant.ru/help/faq/how-can-i-enable-caller-id-for-outbound-calls).

## Согласия и разрешённый сценарий

[Условия «Массовые вызовы» от 07.09.2026](https://voximplant.ru/legal/mass_calls) включают физлиц и автоматический набор. Они требуют предварительных согласий адресатов, их подтверждения по запросу оператора и прекращения звонков после отзыва. В п.5.5 есть широкая формулировка об «Автоматизированных центрах»: допустимость именно связки VoxEngine + ElevenLabs нужно письменно согласовать с оператором.

Наличие согласия и операторской услуги не разрешает автоматически любой рекламный обзвон: [часть 2 статьи 18 закона «О рекламе»](https://www.consultant.ru/document/cons_doc_LAW_58968/f892dec1383709792452f18d36e7043306e2be0a/) отдельно запрещает рекламное автоматическое дозванивание без участия человека в выборе и/или наборе номера. Начните со своих тестовых номеров и согласованного сервисного сценария. Поле согласия в приложении — учёт предоставленного основания; оно не является проверкой законности содержания звонка.

## Как приложение запускает исходящий

`app/providers.py` выполняет **один POST** на фиксированный адрес:

```text
https://api.voximplant.com/platform_api/StartScenarios/
Content-Type: application/x-www-form-urlencoded

account_id=<идентификатор аккаунта>
api_key=<API-ключ аккаунта>
rule_id=<идентификатор routing rule>
script_custom_data={"job_id":"…","dispatch_token":"…"}
```

Все параметры находятся в теле HTTPS-запроса. Номер клиента и сведения о продукте не передаются в `script_custom_data`; сценарий получает их после однократного разрешения backend. Размер compact JSON ограничен 199 байтами. Dispatch token — секрет конкретной попытки: не публикуйте его и не включайте подробное журналирование HTTP-тел.

Используется API-ключ, а не содержимое JSON сервисного аккаунта. JWT сервисного аккаунта — другой поддерживаемый способ авторизации, но в этот адаптер он не добавлен. [Management API basics](https://docs.voximplant.ai/platform/management-api/basics), [авторизация](https://docs.voximplant.ai/platform/management-api/authorization), [официальный пример POST](https://docs.voximplant.ai/getting-started/inbound-vs-outbound/outbound-calls).

Успешный ответ содержит числовое `result: 1`; `call_session_history_id`, когда присутствует, сохраняется как идентификатор истории провайдера. Это подтверждает принятие сценария, **не ответ абонента и не успешный разговор**. Ссылки `media_session_access_url` не сохраняются и не вызываются; остановка выполняется через опрос сценария к backend.

### Почему при ошибке нет автоматического повторного звонка

Таймаут может произойти после принятия запроса платформой. Поэтому потеря связи, 5xx, HTTP 502, редирект, неясный/противоречивый JSON и внутренние ошибки API означают **неопределённый результат**. Не запускайте тот же контакт повторно, пока не проверите историю Voximplant и состояние задания. Транспорт не повторяет запрос и не следует редиректам.

Только известные ошибки предварительной проверки — например, авторизация, неверное правило или недостаточный баланс — классифицируются как явный отказ, если ответ не содержит признаков созданной сессии. Сообщения провайдера могут содержать служебные данные, поэтому приложение выводит собственный безопасный текст и при необходимости числовой код. Основание формата и значений — [каталог ошибок Management API](https://docs.voximplant.ai/api-reference/management-api/errors).

## Стоимость

Ориентиры [публичного прайса РФ](https://voximplant.ru/pricing) на дату проверки. Рублёвые значения прочитаны из встроенных данных страницы, а не пересчитаны самостоятельно из USD. Действующие условия конкретного кабинета, налоги и доступность номера требуется проверить перед оплатой.

| Статья | Публичный ориентир |
|---|---:|
| Обычный городской/мобильный номер | 350 ₽/месяц |
| Москва 495 | 550 ₽/месяц |
| РФ → стационарный РФ | от 0,93 ₽/мин |

В [global-прайсе](https://voximplant.com/pricing) ElevenLabs Agents Client указан в Voice AI Connectors по **$0,004/мин за двунаправленный поток**, шаг 15 секунд. Стоимость ElevenLabs добавляется отдельно. Применимость и ставка коннектора в российском аккаунте должны быть подтверждены; не прибавляйте одновременно коннектор и WebSocket как две доказанные обязательные услуги.

[FAQ Voximplant](https://voximplant.ru/help/faq/how-are-minutes-rounded-for-billing) описывает округление телефонных минут вверх. У AI-компонентов могут быть другие единицы учёта. Плата за попытку и плата за отвеченный разговор также различаются.

### ElevenLabs Agents

По [прайсу ElevenAgents](https://elevenlabs.io/pricing/agents): Starter **$6/месяц и 75 минут**, Creator **$22 и 275 минут**, Pro **$99 и 1 238 минут**. Обычные дополнительные минуты — **$0,08/мин**; при включённом burst и превышении параллельности — **$0,16/мин**. LLM и телефонный оператор оплачиваются отдельно, цены без налогов. Временные скидки первого месяца в эти ориентиры не включены.

### Пример оценки

100 отвеченных исходящих разговоров ровно по три минуты дают 300 телефонных минут. По минимальной опубликованной мобильной ставке это **498 ₽ только за PSTN-плечо**, плюс номер, AI, коннектор и применимые сборы. Если оплачивается 100 попыток услуги массовых вызовов, добавляется 30 ₽; неуспешные дополнительные попытки увеличат эту статью.

Итого: **номер + телефонные минуты + ElevenLabs + LLM + Voximplant AI-коннектор + применимые платежи за попытки + сервер/хранение + налоги, не включённые в ставки**. Расчёт является иллюстрацией, не обещанным бюджетом. Для нового российского аккаунта Platform фиксированный бесплатный пакет минут не подтверждён. Сравните детализации после первых согласованных тестов.
