# AI Calls — самостоятельные звонки через ElevenLabs

Небольшой отдельный сервис: вы добавляете согласованные контакты и цель разговора, ставите звонки в очередь, нажимаете «Запустить». **Voximplant набирает российский номер, ElevenLabs разговаривает, приложение сохраняет результат.** CRM не нужна.

Стек: **Voximplant Platform + ElevenLabs Agents + Python/FastAPI + SQLite**. Яндекс, Telegram и CRM не используются. Голос идёт между телефонной платформой и ElevenLabs напрямую; ваш сервер управляет заданиями, а не передаёт аудио.

Это исходный код для развёртывания в ваших аккаунтах. Локально проверены логика и интеграционные контракты с подменёнными ответами сервисов. **Реальный звонок, голос, доступность российского маршрута и списания без ваших аккаунтов не проверены.** Режим по умолчанию — `mock`, он никуда не звонит.

## Что уже работает в проекте

- Простая русская панель: контакты, CSV, очередь, время запуска, результаты, остановка.
- Самостоятельный набор и голосовой диалог через нативный ElevenLabs client в VoxEngine.
- Настраиваемые факты о продукте, имя собеседника и цель разговора.
- Перебивание речи агента, предел длительности, обработка занятости и отсутствия ответа.
- Итог разговора отдельно от состояния линии: интерес, отказ, просьба о перезвоне, ошибочный адресат, неизвестно.
- Текст разговора и реальные идентификаторы сессий, если они пришли от провайдера.
- Постоянный список «не звонить»: отказ отменяет будущие задания и останавливает активное.
- Проверка зафиксированного согласия, разрешённых номеров, местного времени и лимитов.
- Одноразовое разрешение перед набором; одинаковое задание не запускает второй вызов.
- При неопределённом ответе провайдера — пауза и ручная сверка, без автоматического повтора.
- Docker, HTTPS через Caddy, резервная копия SQLite, автоматические тесты в GitHub Actions.

`mock` показывает синтетический разговор и не проверяет качество AI. Здесь нет покупки номеров через приложение, оплаты, CRM-воронки, автоматического перезвона, обещанного распознавания автоответчиков или аудиозаписи. С просьбой о перезвоне создаётся результат `callback`; новое задание назначает оператор.

## Самый быстрый старт: попробовать панель бесплатно

Нужен Python **3.13**. Из каталога проекта:

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/init_env.py
uvicorn app.main:create_app --factory --host 127.0.0.1 --port 8000 --workers 1
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). Возьмите `ADMIN_TOKEN` из созданного локального `.env` и введите в панели. Скрипт создаёт два разных случайных секрета и `config/product.json`; существующие файлы не перезаписывает. Не отправляйте `.env` в GitHub и не вставляйте его в переписки.

1. Проверьте надпись **MOCK · без звонков**.
2. Добавьте свой российский номер, часовой пояс, источник и время согласия на тест.
3. Нажмите возле него «В очередь», затем «Запустить очередь».
4. В разрешённое время появится синтетический результат примерно через несколько секунд. Кнопка «Открыть» покажет тестовый текст.

По умолчанию окно звонков **09:00–20:00 по времени контакта**, даже в mock. Для ночной проверки исключительно mock можно временно задать `CALL_WINDOW_START=0`, `CALL_WINDOW_END=24` и перезапустить сервер. Перед реальными вызовами верните согласованное окно.

Панель после перезапуска страницы запрашивает токен снова: он хранится только в памяти вкладки. После перезапуска самого сервера очередь всегда на паузе. Нажмите «Запустить» явно.

## Как включить реальные звонки

Понадобятся два аккаунта, активный российский номер/Caller ID и сервер с публичным HTTPS. Подробные шаги создания агента и сценария: **[docs/voximplant.md](docs/voximplant.md)**.

### 1. Проверьте доступность провайдеров

У Voximplant/«Фастком» опубликован договор для **физического лица**: ИП/ООО не является общим обязательным условием. Но нужны идентификация, документы и подходящие условия подключения; это не анонимная телефония. В текущей форме договора предусмотрена УКЭП либо УНЭП. Доступность конкретного номера и автоматизированного сценария подтвердите у оператора. [Документы и точные оговорки](docs/costs-and-provider.md#подключение-физического-лица).

У ElevenLabs есть [официальные ограничения доступа из России и Беларуси](https://elevenlabs.io/docs/help-center/legal/do-you-restrict-access-to-the-service-and-platform-for-any-specific-countries). Российский номер получателя и страна доступа владельца API — разные вещи. Прежде чем платить, проверьте допустимость вашего аккаунта, оплаты и размещения серверов. Проект оставляет выбранный вами ElevenLabs и не предлагает обход ограничений.

### 2. Настройте продукт и агента

В `config/product.json` укажите собственные проверенные сведения:

```json
{
  "name": "Название вашего продукта",
  "call_goal": "Помочь пользователю разобраться с его ранее оформленной заявкой.",
  "facts": [
    "Вставьте здесь реальное описание продукта.",
    "Укажите действующие условия и что помощник вправе сообщать."
  ],
  "ready_for_live": false
}
```

После замены всех примеров и проверки сценария установите `ready_for_live: true`. Приложение проверяет наличие фактов и этого флага, но не проверяет их достоверность. Не добавляйте секреты и лишние персональные данные.

Создайте ElevenLabs Agent: русский язык, ваш разрешённый голос, первая реплика и System prompt из [agent-prompt.md](voximplant/agent-prompt.md), клиентские инструменты из [tools.json](voximplant/tools.json). Для инструментов включите ожидание ответа. Переменные: `product_name`, `product_facts`, `call_goal`, `contact_name`. Агент честно представляется ИИ; сведений о вашем неизвестном продукте в коде не придумано.

Сценарий Voximplant: [voximplant/outbound.js](voximplant/outbound.js). Скопируйте его целиком в отдельное приложение **Platform**, привяжите к отдельному Routing rule. Voximplant Kit для этой реализации не нужен.

### 3. Разложите настройки по местам

**На вашем сервере, в `.env`:**

| Настройка | Что поставить |
|---|---|
| `MODE` | `live` только после настройки обоих аккаунтов |
| `ADMIN_TOKEN` | Уже создан скриптом; доступ к панели/API |
| `INTERNAL_SECRET` | Второй созданный секрет; связь VoxEngine → сервер |
| `PUBLIC_BASE_URL` | Например `https://calls.example.com`, без пути |
| `DOMAIN` | `calls.example.com`, если используете Caddy |
| `VOXIMPLANT_ACCOUNT_ID` | Числовой Account ID |
| `VOXIMPLANT_API_KEY` | Management API key, не JSON сервисного аккаунта |
| `VOXIMPLANT_RULE_ID` | Числовой ID отдельного Routing rule |
| `CALLER_ID` | Ваш разрешённый российский номер строго `+7…` |
| `ELEVENLABS_AGENT_ID` | ID опубликованного агента `agent_…` |
| `LIVE_ALLOWED_NUMBERS` | Для пилота только свой номер `+7…`; несколько — через запятую |
| `ALLOW_ALL_CONSENTED_NUMBERS` | Оставьте `false` для пилота |

**В Voximplant Application → Secrets:**

| Секрет | Что поставить |
|---|---|
| `ELEVENLABS_API_KEY` | API-ключ ElevenLabs, доступный этому агенту |
| `AI_CALLS_BASE_URL` | Тот же публичный HTTPS-адрес, без `/` в конце |
| `AI_CALLS_INTERNAL_SECRET` | Точное значение серверного `INTERNAL_SECRET` |

ElevenLabs API key не нужен в браузере или `.env` приложения: его использует VoxEngine. Management API key Voximplant остаётся только на сервере. Не включайте подробное логирование запросов с секретами.

### 4. Разверните сервер

Для небольшого пилота можно начать с Linux VPS, Docker Compose, 1–2 CPU и 1–2 ГБ RAM; это стартовая конфигурация, а не результат нагрузочного теста. Аудио не проходит через этот VPS. Выберите регион, допустимый для ваших данных и подключённых сервисов.

```bash
# После создания .env и config/product.json:
docker compose up -d --build
```

Это открывает приложение только на `127.0.0.1:8000` сервера. Для публичного HTTPS направьте DNS A/AAAA вашего домена на VPS, откройте TCP 80/443, задайте `DOMAIN` и `PUBLIC_BASE_URL`:

```bash
docker compose -f compose.yml -f compose.https.yml up -d --build
```

Caddy получает сертификат автоматически при корректных DNS и доступности портов. Базу хранит именованный Docker volume `calls_data`, конфигурация продукта подключается отдельным файлом. Не используйте `docker compose down -v` для обычного обновления — это удаляет данные.

После изменения `.env` перезапустите приложение с пересозданием:

```bash
docker compose -f compose.yml -f compose.https.yml up -d --force-recreate app
```

**Один процесс приложения, `--workers 1`, одна реплика.** Состояние mock и процесс отправки рассчитаны на этот режим; горизонтальное масштабирование в этой версии не заявлено. Не запускайте отдельно второй worker и не используйте `--reload` в live.

### 5. Пройдите один реальный тест

Сначала свой номер, один одновременный вызов и небольшой дневной лимит. Перезапустите с `MODE=live`, войдите в панель, поставьте один контакт в очередь и нажмите запуск. Это уже инициирует платный звонок.

Проверьте слышимость, русский язык, первые фразы, факты продукта, перебивание, отсутствие ответа, остановку и просьбу «Больше не звоните». Затем сверяйте итог с историей Voximplant и ElevenLabs, включая фактические списания. Полный [чек-лист приёмки](docs/voximplant.md#5-приёмка-на-собственном-номере).

Если пилот принят и оператор разрешил сценарий, можно расширить `LIVE_ALLOWED_NUMBERS`. `ALLOW_ALL_CONSENTED_NUMBERS=true` снимает именно пилотный список номеров; согласие, DNC, окно времени и лимиты остаются обязательными.

## Как пользоваться каждый день

Контакт содержит телефон РФ, имя, источник/дату согласия и IANA-часовой пояс, например `Europe/Moscow` или `Asia/Vladivostok`. Проверка формата не доказывает владение номером или доступность линии. Казахстанские `+7` не принимаются как РФ.

CSV — UTF-8, до 500 строк и 256 КБ. Заголовок:

```csv
phone,name,consent_source,consent_at,timezone
```

В `consent_at` передавайте ISO 8601 с часовым поясом, например `2026-10-26T10:00:00+03:00`; используйте настоящую дату своего согласия. При отсутствии колонки `timezone` применяется `DEFAULT_TIMEZONE`. Если колонка есть, значения должны быть заполнены. Невалидные строки отклоняются до записи всего файла; существующие телефоны не дублируются, отчёт показывает частичные конфликты импорта. **Импорт добавляет контакты, но не запускает обзвон.**

Кнопка «В очередь» создаёт задание. Необязательное время над списком — самая ранняя дата старта; это не гарантия звонка в конкретную секунду. Время ввода в браузере относится к часовому поясу устройства, а разрешённое окно вызова — к часовому поясу контакта. Если окно закрыто или лимит исчерпан, задание ждёт.

«Остановить звонки» блокирует новые и посылает остановку активным через опрос сценария. Остановка не мгновенная: обычно один цикл опроса плюс задержка сети. Уже выданная остановка не отменяется быстрым нажатием «Запустить». Кнопка «Стоп» в строке действует на одно задание.

Повторное задание тому же номеру нельзя добавить, пока есть ожидающее, активное или неопределённое. После однозначного завершения оператор может назначить новый звонок; автоматических повторов нет. DNC хранится постоянно, кнопки автоматического снятия запрета нет.

### Ограничения по умолчанию

| Настройка | Значение | Смысл |
|---|---:|---|
| `MAX_CONCURRENT` | 1 | Число одновременно занятых слотов |
| `DAILY_ATTEMPT_LIMIT` | 20 | Резервирования попыток за календарные сутки **UTC** |
| `MAX_DURATION_SEC` | 180 | Максимум после ответа, включая подключение AI |
| `RINGING_TIMEOUT_SEC` | 30 | Максимум ожидания ответа |
| `CALL_WINDOW_START/END` | 9 / 20 | Начало включительно, конец исключительно, по времени контакта |
| `DEFAULT_TIMEZONE` | Europe/Moscow | По умолчанию для новых контактов |

Дневной лимит считают и неуспешные/неопределённые попытки. Это ограничение количества, **не денежный бюджет**. Режимы записываются в заданиях: mock-задание не превращается в платное после смены режима. Для независимых демо и live используйте разные базы.

### Что делать с «Неизвестно»

Таймаут запуска не означает, что звонка не было. Приложение останавливает очередь, сохраняет попытку и не освобождает её для повторного набора. Потерянный финал также обнаруживается по устаревшему состоянию — порог `MAX_DURATION_SEC + RINGING_TIMEOUT_SEC + 120` секунд после резервирования попытки, даже если промежуточные события ещё поступают.

Проверьте активные сессии и историю Voximplant по времени/ID, при необходимости завершите сессию там. В панели откройте задание, укажите проверенный окончательный статус и заметку. Только после проверки всех неизвестных заданий можно возобновить очередь. **Ручное разрешение не завершает удалённую линию само по себе.**

`completed` — завершённое соединение, не доказанная продажа. `interested` — классификация по словам человека, не договор или платёж. Отсутствующие сведения остаются `unknown`.

## Границы использования и данные

Механизм рассчитан на согласованные контакты. Согласие само по себе не делает законным любой сценарий: для рекламного автоматического дозванивания в РФ есть отдельное ограничение в [ч. 2 ст. 18 закона «О рекламе»](https://www.consultant.ru/document/cons_doc_LAW_58968/f892dec1383709792452f18d36e7043306e2be0a/). Пока продукт и содержание разговора не определены, невозможно подтвердить допустимость конкретного обзвона. Условия Voximplant для автоматизированных вызовов и внешнего AI также нужно проверить по вашему договору. [Разбор с источниками](docs/costs-and-provider.md#согласия-и-разрешённый-сценарий).

В SQLite хранятся телефоны, согласия, задания, запреты и ограниченный транскрипт. Аудиозапись Voximplant кодом не включается; хранение записей и транскриптов **в ElevenLabs настраивается отдельно в его кабинете**. Аудио и переменные продукта передаются внешнему провайдеру. Выберите срок хранения, регион и порядок удаления под свой сценарий до работы с клиентами. Автоматического удаления по сроку и шифрования базы на уровне приложения в этой версии нет; ограничьте доступ к диску и копиям.

Транскрипт ограничен 100 репликами, 1 000 символами на реплику и 30 000 суммарно; при усечении есть отдельная отметка. Это доступные события провайдера, не гарантированная дословная запись. Программного резервного голосового провайдера нет: при сбое ElevenLabs звонок завершается.

## Обслуживание и разработка

Резервная копия локального запуска через SQLite backup API:

```bash
python scripts/backup.py data/calls.sqlite3 data/backups
```

Копии содержат персональные данные и внутренние токены попыток: храните их как секретные данные. Для Docker:

```bash
docker compose exec app python scripts/backup.py /data/calls.sqlite3 /data/backups
docker compose cp app:/data/backups ./data/
```

Не копируйте один работающий `.sqlite3` без WAL; скрипт использует SQLite backup API. Не публикуйте каталог `data/`. При восстановлении остановите приложение, верните проверенную копию и уберите старые WAL/SHM только для заменяемой базы; учтите, что восстановление старой копии может вернуть старую очередь и потерять поздние запреты звонков. Сначала сверяйте DNC и историю, затем возобновляйте очередь вручную.

Тесты не требуют платных ключей и не выполняют телефонных вызовов:

```bash
python -m pip install -r requirements-dev.txt
ruff check app scripts tests
pytest -q
node --test tests/scenario.test.cjs
```

Используются Python 3.13 и Node 22. Зависимости закреплены в `requirements*.txt`, исходные диапазоны — в `.in`. GitHub Actions повторяет эти проверки и запускает Docker в mock. [Результаты проверки и её границы](docs/validation.md). `GET /health` показывает, что сервер жив; это не проверка готовности телефонии.

Структура: `app/store.py` — очередь и события; `app/worker.py` — отправка; `app/providers.py` — Management API; `voximplant/outbound.js` — телефонная линия и AI; `app/static/` — панель. **[Описание API](docs/api.md)** для подключения к вашему проекту.

Реализация написана отдельно для этого репозитория после разбора [polygraph-ai-sales](https://github.com/ADAMANTOBLAST/polygraph-ai-sales). Код CRM не переносился. Основные источники интеграции — официальные [Voximplant outbound](https://docs.voximplant.ai/voice-ai-orchestration/elevenlabs/outbound), [VoxEngine API](https://docs.voximplant.ai/api-reference/voxengine/elevenlabs/overview), [динамические переменные ElevenLabs](https://elevenlabs.io/docs/eleven-agents/customization/personalization/dynamic-variables) и [client tools](https://elevenlabs.io/docs/eleven-agents/customization/tools/client-tools).
